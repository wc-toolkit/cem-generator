Add `@wc-toolkit/cem-generator-lwc`, a detector plugin for Salesforce Lightning Web Components. It documents `@api` properties as attributes and members, `@api` methods, dispatched `CustomEvent`s, template slots, and bundle-based tag names. The CLI `--plugin` option now accepts `lwc`.
