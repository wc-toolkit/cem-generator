## Prerequisites

- Node.js 20+
- npm

## Install and run

```bash
npm install
npm run build
npm test
```

## Demos

```bash
npm run demo:core
npm run demo:core-utils
npm run demo:lit
npm run demo:all
```

Integration example:

```bash
npm run example
```

## Docs site

```bash
npm run docs:dev
npm run docs:build
npm run docs:preview
```
